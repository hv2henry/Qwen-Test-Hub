    About Notes

    Notes is a single-page notebook. There is no account, no server and no tracking — your notes are stored by your browser on this device and never sent anywhere.

    Keyboard

    • N — start a new note
    • / — jump to search
    • Ctrl+Enter — save the note you're typing
    • Esc — close a dialog or clear the search

    Tags

    Write #anything inside a note and it becomes a tag automatically. Click a tag chip to filter; click it again to clear.

    Keeping your notes safe

    Because everything lives in this browser, clearing your browser data will erase it. Use Backup now and then — it downloads a small .json file that Restore can read back on any device.

    Install

    Served over HTTPS, Notes can be installed to your desktop or home screen and works offline. Opened as a plain file it still works, just without installing.
